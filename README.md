# quipmug

A personal collection of projects, notes, and ideas.

**[View quipmug](https://quipmug.github.io/portfolio-board/)**

## Owner access

Open [the owner route](https://quipmug.github.io/portfolio-board/?manage=1), or press and hold the bunny in the footer for about a second to open sign-in. Use your registered owner email.

Once signed in, the owner workspace provides entry publishing, private drafts, contacts and introduction editing. The hidden shortcut does not grant access; the existing account and database permissions still apply.
